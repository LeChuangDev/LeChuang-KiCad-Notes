# 布线规则与技巧

## 布线基础
- 按 `X` 开始布线
- 点击焊盘或导线端点开始
- 双击结束布线
- 按 `Esc` 取消
- 布线模式：高亮碰撞、推挤、绕行（在交互式布线设置中选择）

## 布线模式
| 模式 | 说明 |
|------|------|
| Highlight Collisions | 完全手动，碰撞高亮显示 |
| Shove | 自动推挤可移动障碍物 |
| Walk Around | 绕过障碍物，不推挤 |

## 布线转角模式
- 45 度（默认）
- 45 度圆角
- 90 度
- 90 度圆角
- 使用 `Ctrl + /` 循环切换

## 过孔放置
- 按 `V` 放置过孔并切换层
- 支持微孔、盲孔、埋孔
- `Ctrl + V` 放置微孔
- `Alt + Shift + V` 放置盲孔/埋孔
- 过孔尺寸可预设，布线时切换

## 差分对布线
- 网络名需以 `+`/`-`、`_P`/`_N` 或 `P`/`N` 结尾
- 按 `6` 开始差分对布线
- 自动创建两个相邻过孔
- 支持差分对间隙和长度调整

## 长度调整
- 单轨长度调整：按 `7`
- 差分对长度调整：按 `8`
- 差分对偏移调整：按 `9`
- 支持蛇形线、圆角、单边模式
- 可设置目标长度和偏移

## 敷铜
- 按 `Ctrl + Shift + Z` 添加填充区域
- 选择网络、层、间隙、最小宽度
- 焊盘连接方式：实心、热焊盘、无
- 按 `B` 填充所有敷铜
- 按 `Ctrl + B` 取消填充
- 支持网格敷铜

## 布线技巧
1. **先布关键信号**：时钟、差分对、高速信号
2. **保持参考平面完整**：避免跨分割
3. **控制阻抗**：使用网络类或自定义规则
4. **避免直角**：使用 45 度或圆弧
5. **最小化过孔**：减少寄生参数
6. **电源和地**：使用敷铜或宽走线
7. **散热**：大电流路径加宽，添加散热过孔

## 清理工具
- `Tools → Cleanup Tracks & Vias`：删除冗余过孔、合并共线走线
- `Tools → Remove Unused Pads`：移除未使用的焊盘环形圈
- `Edit → Edit Track & Via Properties`：批量编辑走线和过孔
