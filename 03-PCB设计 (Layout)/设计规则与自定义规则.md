# 设计规则与自定义规则

## 设计规则概述
- 控制交互式布线器、敷铜填充、DRC 检查
- 在 `Board Setup → Design Rules` 中配置
- 规则优先级：自定义规则 > 网络类 > 板级约束

## 约束 (Constraints)
- 全局最小/最大值，不可被更具体规则覆盖
- 最小间隙、最小线宽、最小连接宽度
- 最小环形圈、最小过孔直径、孔到铜间隙
- 铜到边缘间隙、最小钻孔尺寸、孔到孔间隙

## 网络类 (Net Classes)
- 为不同网络组分配设计规则
- 可设置间隙、线宽、过孔尺寸、差分对尺寸
- 支持基于模式的分配（通配符、正则表达式）
- 可在原理图或 PCB 中分配

## 自定义规则 (Custom Rules)
- 类 S 表达式语法
- 存储在 `.kicad_dru` 文件中
- 规则从下往上评估（最后一条最先检查）
- 支持条件、约束、层、严重程度

### 基本语法
```scheme
(version 1)
(rule <名称>
  [(severity <严重程度>)]
  [(layer <层>)]
  [(condition <表达式>)]
  (constraint <约束类型> <参数>))```
```
### 常用约束类型

|类型|参数|说明|
|---|---|---|
|clearance|min|铜对象之间的间隙|
|track_width|min/opt/max|布线宽度|
|via_diameter|min/opt/max|过孔直径|
|hole_size|min/opt/max|孔径|
|diff_pair_gap|min/opt/max|差分对间隙|
|length|min/opt/max|网络长度|
|skew|min/opt/max|偏移|
|courtyard_clearance|min|外框间隙|
|silk_clearance|min|丝印间隙|
|edge_clearance|min|到板边间隙|
|physical_clearance|min|物理间隙|
|disallow|对象类型|禁止对象|
|assertion|布尔表达式|断言|

### 条件表达式

- 对象属性：`A.NetName`、`A.Layer`、`A.Type`、`A.Reference`、`A.Value` 等
    
- 函数：`A.hasNetclass('HV')`、`A.inDiffPair('/USB')`、`A.intersectsArea('zone1')`、`A.memberOfFootprint('U1')` 等
    
- 运算符：`==`、`!=`、`>`、`>=`、`<`、`<=`、`&&`、`||`、`!`
    
- 单位：`mm`、`mil`、`in`、`deg`、`rad`
    

### 示例

scheme

# 高压网络间隙
(rule HV
  (condition "A.hasNetclass('HV')")
  (constraint clearance (min 1.5mm)))
# 电源网络线宽
(rule PWR_track
  (condition "A.hasNetclass('PWR')")
  (constraint track_width (min 0.5mm) (opt 0.5mm) (max 1.0mm)))
# 禁止在特定区域布线
(rule "copper keepout"
  (constraint disallow track via zone)
  (condition "A.intersectsArea('zone3')"))
# 差分对间隙
(rule "Clock gap"
  (condition "A.inDiffPair('/CLK')")
  (constraint diff_pair_gap (opt 0.8mm)))
# 长度匹配
(rule "DDR_DQ length"
  (condition "A.fromTo('U1-A*', 'U2-B*')")
  (constraint length (max 50mm)))

## 图形化设计规则编辑器

- `Tools → Design Rule Editor`
    
- 左侧规则树，右侧规则编辑器
    
- 支持电气、可制造性、高速设计、封装、自定义五类
    
- 可视化编辑，自动生成规则文本
    

## 违规严重程度

- 在 `Board Setup → Violation Severity` 中配置
    
- 可设置为错误、警告、忽略
    
- 忽略规则仍会被评估，可覆盖之前的规则

# 符号库管理
## 符号库表
- 全局符号库表：所有工程可用
- 工程专用符号库表：仅当前工程可用
- 管理：`Preferences → Manage Symbol Libraries`
## 支持的库格式
- KiCad 符号库（`.kicad_sym`）
- KiCad 旧版符号库（`.lib`）
- Altium Designer（`.SchLib`、`.IntLib`）
- CADSTAR（`.lib`）
- Eagle（`.xml`）
- EasyEDA 标准版（`.json`）
- EasyEDA 专业版（`.elibz`、`.epro`、`.zip`）
## 库表条目
- 昵称：唯一标识，不能包含冒号
- 路径：绝对路径、相对路径或路径变量
- 格式：选择正确的库格式
- 启用/显示：控制库是否加载和显示
- 描述：可选描述
## 嵌套库表
- 库表可以包含其他库表
- 用于分离库组，便于共享
- KiCad 默认库表就是一个嵌套库表
## 路径变量
- `${KICAD10_SYMBOL_DIR}`：KiCad 标准符号库路径
- `${KIPRJMOD}`：当前工程目录
- 自定义路径变量：`Preferences → Configure Paths`
## 迁移库
- 非 KiCad 格式库为只读
- 使用 `Migrate Libraries` 按钮转换为 KiCad 格式
- 也可在符号编辑器中另存为新库
## 符号编辑器
- 启动：从工程管理器或原理图编辑器
- 可编辑库符号或原理图中的符号副本
- 支持创建、编辑、删除、复制、导出符号
- 支持从其他库导入符号
## 符号创建流程
1. 定义符号名称、位号前缀、单元数
2. 绘制符号图形（线条、矩形、圆形、圆弧）
3. 添加引脚，定义引脚名称、编号、电气类型
4. 添加字段（封装、数据手册、描述等）
5. 设置封装筛选器
6. 保存到库
## 引脚电气类型
| 类型 | 说明 |
|------|------|
| Input | 输入 |
| Output | 输出 |
| Bidirectional | 双向 |
| Tri-state | 三态 |
| Passive | 无源 |
| Free | 自由 |
| Unspecified | 未指定 |
| Power input | 电源输入 |
| Power output | 电源输出 |
| Open collector | 开集电极 |
| Open emitter | 开射极 |
| Unconnected | 未连接 |
## 引脚堆叠
- 多个引脚在同一位置，自动连接
- 支持 `[1-3]` 格式表示多个编号
- 可转换为独立引脚或合并
## 派生符号
- 从现有符号派生，共享图形和引脚
- 可覆盖字段、描述、封装筛选器
- 必须与基础符号在同一库中
