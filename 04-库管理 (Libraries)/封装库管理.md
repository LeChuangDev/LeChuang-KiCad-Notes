# 封装库管理

## 封装库表
- 全局封装库表：所有工程可用
- 工程专用封装库表：仅当前工程可用
- 管理：`Preferences → Manage Footprint Libraries`

## 支持的库格式
- KiCad 封装库（`.pretty` 文件夹，包含 `.kicad_mod` 文件）
- KiCad 旧版封装库（`.mod`）
- Altium Designer（`.PcbLib`、`.IntLib`）
- CADSTAR（`.cpa`）
- Eagle（`.lbr`）
- EasyEDA 标准版（`.json`、`.zip`）
- EasyEDA 专业版（`.elibz`、`.epro`、`.zip`）
- gEDA（`.fp` 文件夹）

## 封装编辑器
- 启动：从工程管理器或 PCB 编辑器
- 可编辑库封装或 PCB 中的封装副本
- 支持创建、编辑、删除、复制、导出封装
- 支持从其他库导入封装

## 封装创建流程
1. 创建新库或选择现有库
2. 创建新封装，设置名称、值、类型
3. 添加焊盘，设置位置、尺寸、形状、孔径
4. 绘制图形（丝印、制造层、外框）
5. 添加 3D 模型
6. 运行封装检查器
7. 保存到库

## 焊盘属性
| 属性 | 说明 |
|------|------|
| 类型 | SMD、通孔、边缘连接器、NPTH |
| 形状 | 圆形、矩形、椭圆形、圆角矩形、自定义 |
| 尺寸 | X/Y 尺寸、孔径 |
| 层 | 铜层、技术层 |
| 网络 | 焊盘连接的网络 |
| 制造属性 | BGA、基准点、测试点、散热焊盘等 |

## 封装图形
- 丝印层（F.Silkscreen / B.Silkscreen）：元件轮廓
- 制造层（F.Fab / B.Fab）：精确轮廓
- 外框层（F.Courtyard / B.Courtyard）：物理边界
- 铜层：可创建电气连接

## 3D 模型
- 支持 STEP、VRML、IDF 格式
- 在封装属性 → 3D Models 中添加
- 可设置偏移、缩放、旋转、透明度
- 可嵌入封装文件

## 封装检查器
- 检查外框、焊盘、丝印、阻焊等问题
- 检查焊盘与封装类型是否匹配
- 检查通孔焊盘是否有孔
- 检查丝印与阻焊是否冲突

## 封装向导
- 支持 BGA、QFN、QFP、SOIC、DIP 等常见封装
- 输入参数自动生成封装
- 可手动修改生成的封装
