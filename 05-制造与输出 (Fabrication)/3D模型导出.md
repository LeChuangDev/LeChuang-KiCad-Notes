# 3D 模型导出

## 导出步骤
1. `File → Export → STEP / GLB / BREP / XAO / PLY / STL`
2. 选择格式和输出文件名
3. 配置导出选项
4. 点击 `Export`

## 支持的格式
| 格式 | 说明 |
|------|------|
| STEP | 机械 CAD 常用，精度高 |
| GLB | 二进制 glTF，适合可视化 |
| BREP | OCCT 原生边界表示 |
| XAO | SALOME/Gmsh，适合物理仿真 |
| PLY | 多边形文件格式 |
| STL | 3D 打印常用 |
| STPZ | GZIP 压缩的 STEP |
| U3D | 通用 3D 格式 |
| PDF | 嵌入 3D 模型的 PDF |

## 导出选项
### 板选项
- Export board body：导出板体
- Cut vias in board body：在板体上切孔
- Export silkscreen：导出丝印
- Export solder mask：导出阻焊
- Export components：导出元件模型

### 导体选项
- Export tracks and vias：导出布线和过孔
- Export pads：导出焊盘
- Export zones：导出敷铜
- Export inner conductor layers：导出内层导体
- Fuse shapes：合并重叠几何体（耗时）
- Fill all vias：填充所有过孔

### 其他选项
- Ignore 'Do not populate' components：忽略 DNP 元件
- Ignore 'Unspecified' components：忽略未指定类型元件
- Substitute similarly named models：替换同名模型
- Overwrite old file：覆盖旧文件

## 3D 查看器
- 按 `Alt + 3` 打开
- 鼠标左键拖动旋转
- 鼠标中键拖动平移
- 滚轮缩放
- 支持光线追踪模式
- 可导出 PNG 图片
- 可复制到剪贴板

## VRML 导出
- `File → Export → VRML`
- 适合视觉展示，精度要求不高
- 选项：忽略 DNP 元件、忽略未指定元件、复制模型文件等

## IDF 导出
- `File → Export → IDFv3`
- 用于机械 CAD 软件
- 导出板框、切口、焊盘、安装孔、元件外框
- 需要为封装附加 IDF 模型
