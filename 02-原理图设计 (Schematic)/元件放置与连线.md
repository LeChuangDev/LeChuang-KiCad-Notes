# 元件放置与连线

## 放置符号
- 按 `A` 打开符号选择器
- 选择符号后点击画布放置
- 可勾选 `Place repeated copies` 连续放置
- 多单元符号可勾选 `Place all units`

## 移动与旋转
| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 移动 | `M` | 移动符号，不保持导线连接 |
| 拖动 | `G` | 移动符号，保持导线连接 |
| 旋转 | `R` | 逆时针旋转 90° |
| 水平镜像 | `X` | 左右翻转 |
| 垂直镜像 | `Y` | 上下翻转 |

## 编辑符号属性
- 双击符号或按 `E` 打开属性对话框
- 可编辑：位号、值、封装、数据手册、自定义字段
- 可设置字段可见性、对齐方式、字体、颜色
- 可添加/删除自定义字段

## 引脚功能
- 支持备用引脚功能（Alternate Pin Functions）
- 在符号属性 → `Pin Functions` 中定义
- 在原理图中可为每个引脚选择不同功能

## 更新符号
- 库符号更新后，原理图中的符号不会自动更新
- 使用 `Tools → Update Symbols from Library` 手动更新
- 可比较原理图符号与库符号的差异

## 符号字段表
- `Tools → Bulk Edit Symbol Fields` 打开
- 表格形式编辑所有符号字段
- 支持分组、排序、筛选、导出 BOM
- 支持虚拟字段（`${QUANTITY}`、`${ITEM_NUMBER}` 等）

## 连线技巧
- 从引脚端点开始绘制导线，自动吸附
- 使用 50 mil 网格对齐引脚
- 未连接引脚显示小圆圈，连接后消失
- 使用 `No Connection` 标志标记故意不连接的引脚
