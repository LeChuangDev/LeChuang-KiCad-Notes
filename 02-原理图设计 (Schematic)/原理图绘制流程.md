# 原理图绘制流程

## 基本步骤
1. **页面设置**：`File → Page Settings`，设置标题、日期、纸张大小
2. **放置符号**：按 `A` 打开符号选择器，从库中选择符号
3. **放置电源符号**：按 `P`，选择 VCC、GND 等
4. **绘制导线**：按 `W`，点击引脚开始绘制，双击结束
5. **添加标签**：按 `L`，放置本地/全局/层次标签
6. **添加总线**：按 `B`，绘制总线
7. **批注**：自动或手动分配位号
8. **分配封装**：`Tools → Assign Footprints`，为每个符号选择封装
9. **ERC 检查**：`Inspect → Electrical Rules Checker`，检查电气规则
10. **生成 BOM**：`Tools → Generate Bill of Materials`

## 符号放置
- 按 `A` 打开符号选择器
- 支持搜索：名称、关键字、描述
- 支持通配符：`*` 匹配任意字符，`?` 匹配单个字符
- 支持正则表达式
- 可预览符号和默认封装

## 导线绘制
- 按 `W` 开始绘制
- 点击引脚或导线端点自动开始
- 双击结束绘制
- 按 `Esc` 取消
- 导线模式：90 度、45 度、自由角度（`Shift + Space` 切换）

## 结点
- 交叉导线不会自动连接，需手动放置结点
- 按 `J` 放置结点
- 结点会自动添加到 T 型连接处

## 标签
| 类型 | 连接范围 | 快捷键 |
|------|----------|--------|
| 本地标签 | 同一页面内 | `L` |
| 全局标签 | 整个原理图 | `Ctrl + L` |
| 层次标签 | 子图与父图之间 | `H` |

## 总线
- 矢量总线：`DATA[0..7]`
- 分组总线：`{SCL SDA}` 或 `USB1{DP DM}`
- 总线别名：在 `Schematic Setup → Bus Alias Definitions` 中定义
- 总线展开：右键总线 → `Unfold from Bus`

## 批注
- 自动批注：`Preferences → Schematic Editor → Editing Options → Automatically annotate symbols`
- 手动批注：`Tools → Annotate Schematic`
- 支持按 X/Y 位置排序，支持编号重置

## ERC 检查
- 检查未连接引脚、电源冲突、标签冲突等
- 可配置违规严重程度
- 可排除特定违规
