# 常见报错与解决方案

## 原理图 ERC 错误
| 错误 | 原因 | 解决方法 |
|------|------|----------|
| Input Power pin not driven | 电源网络没有输出电源引脚驱动 | 添加 PWR_FLAG 符号 |
| Pin not connected | 引脚未连接 | 连接引脚或添加 No Connection 标志 |
| Label not connected | 标签未连接到任何对象 | 检查标签位置 |
| Global label only appears once | 全局标签只出现一次 | 检查是否需要全局标签 |
| Duplicate reference designators | 位号重复 | 重新批注 |
| Symbol is not annotated | 符号未批注 | 运行批注工具 |
| Unresolved text variable | 文本变量未定义 | 在 Schematic Setup 中定义变量 |

## PCB DRC 错误
| 错误 | 原因 | 解决方法 |
|------|------|----------|
| Clearance violation | 间隙不足 | 调整布线或修改规则 |
| Track has unconnected end | 布线末端未连接 | 连接或删除 |
| Via is not connected | 过孔未连接 | 检查过孔位置 |
| Board edge clearance violation | 铜到板边间隙不足 | 调整位置或修改规则 |
| Courtyards overlap | 封装外框重叠 | 调整布局 |
| Silkscreen clipped by solder mask | 丝印被阻焊裁剪 | 调整丝印位置 |
| Missing connection | 未连接 | 布线连接 |
| Footprint doesn't match symbol | 封装不匹配 | 更新 PCB 或原理图 |
| Pad net doesn't match schematic | 焊盘网络不匹配 | 更新 PCB |
| Isolated copper fill | 孤岛铜 | 删除或连接 |
| Copper sliver | 铜屑 | 调整布线或敷铜 |
| Annular width | 环形圈宽度不足 | 调整焊盘或过孔尺寸 |

## 常见问题
### 符号引脚无法连接
- 检查引脚是否在 50 mil 网格上
- 检查导线是否在 50 mil 网格上
- 使用 `Align Items to Grid` 对齐

### 敷铜无法填充
- 检查板框是否闭合
- 检查敷铜是否在板框内
- 按 `B` 重新填充
- 检查敷铜优先级

### 3D 模型不显示
- 检查封装是否分配了 3D 模型
- 检查模型路径是否正确
- 检查模型格式是否支持
- 在 3D 查看器中启用模型显示

### 网表导出失败
- 检查符号是否全部批注
- 检查封装是否全部分配
- 检查 ERC 是否通过
- 检查库表是否正确配置

## 快捷键冲突
- `Preferences → Hotkeys` 中查看和修改
- 可导入/导出快捷键配置
- 双击命令添加/修改快捷键
- 冲突时会提示
