# KiCad 环境配置与偏好设置

## 首次启动配置
- 选择是否导入旧版本设置
- 选择库表配置方式（默认使用内置库）
- 设置更新和隐私选项

## 路径变量
| 变量名 | 说明 |
|--------|------|
| KICAD10_SYMBOL_DIR | 符号库路径 |
| KICAD10_FOOTPRINT_DIR | 封装库路径 |
| KICAD10_3DMODEL_DIR | 3D 模型路径 |
| KICAD10_TEMPLATE_DIR | 工程模板路径 |
| KIPRJMOD | 当前工程目录（自动设置） |
| SPICE_LIB_DIR | SPICE 模型库路径（默认未定义） |

## 偏好设置
- **通用**：抗锯齿、文本编辑器、PDF 查看器、图标主题
- **鼠标和触摸板**：缩放速度、拖动行为、滚动手势
- **快捷键**：自定义快捷键，可导入/导出
- **工程备份**：自动备份、备份格式、备份位置
- **版本控制**：Git 集成设置

## 库管理
- 全局库表：所有工程可用
- 工程专用库表：仅当前工程可用
- 使用 `Preferences → Manage Symbol Libraries` 管理符号库
- 使用 `Preferences → Manage Footprint Libraries` 管理封装库
