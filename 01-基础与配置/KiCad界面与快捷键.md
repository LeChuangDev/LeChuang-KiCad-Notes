# KiCad 界面与快捷键

## 界面组成
- **工程管理器**：管理工程文件、启动其他工具
- **原理图编辑器**：绘制原理图
- **PCB 编辑器**：布局布线
- **符号编辑器**：创建/编辑符号
- **封装编辑器**：创建/编辑封装
- **Gerber 查看器**：预览 Gerber 文件
- **3D 查看器**：查看 PCB 3D 模型
- **计算器工具**：电阻、电容、线宽等计算

## 常用快捷键

### 通用
| 快捷键 | 功能 |
|--------|------|
| Ctrl + N | 新建 |
| Ctrl + O | 打开 |
| Ctrl + S | 保存 |
| Ctrl + Z | 撤销 |
| Ctrl + Y | 重做 |
| Ctrl + F | 查找 |
| Ctrl + Shift + F | 查找并替换 |
| Ctrl + F1 | 显示快捷键列表 |
| Ctrl + , | 打开偏好设置 |

| 快捷键 | 功能 |
|--------|------|
| A | 放置符号 |
| P | 放置电源符号 |
| W | 绘制导线 |
| B | 绘制总线 |
| L | 放置标签 |
| J | 放置结点 |
| C | 复制 |

| G | 拖动 |

| 快捷键 | 功能 |
|--------|------|

| V | 放置过孔 |
| D | 拖动 |
| M | 移动 |
| R | 旋转 |
| F | 翻转 |
| E | 编辑属性 |
| Del | 删除 |

### 3D 查看器
| 快捷键 | 功能 |
|--------|------|
| Alt + 3 | 打开 3D 查看器 |
| Space | 重置轴心点 |

## 常用操作
- **平移**：鼠标中键或右键拖动
- **缩放**：鼠标滚轮或 F1 / F2
- **选择**：左键单击，Shift + 单击添加，Ctrl + 单击切换
- **框选**：从左到右只选完全包含的对象，从右到左选所有接触的对象
